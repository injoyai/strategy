# 界面操作需求与前端方案

状态：Proposed，2026-09-12。本轮定义界面需求，不包含已实现的页面。

## 1. 前端技术选择

选择 React + TypeScript + Vite 构建 SPA，Ant Design 提供维护中的表单、表格、日期选择和弹窗组件，Apache ECharts 提供金融研究图表。HTTP 客户端由 OpenAPI 生成；远程状态与缓存集中管理，研究配置和最终计算以 Go 后端为准。

采用 SPA 是因为核心是登录后的研究工作台，不依赖搜索引擎页面渲染。Go 可托管构建产物，前端也可独立部署。依赖版本、请求状态库及路由库在开发时锁定并验证。

选型依据：React 官方提供 TypeScript 与 Vite 建项说明，Ant Design 提供 Vite 集成文档。[React TypeScript](https://react.dev/learn/typescript)、[React 构建说明](https://react.dev/learn/build-a-react-app-from-scratch)、[Ant Design Vite](https://ant.design/docs/react/use-with-vite/)。图表能力参见 [Apache ECharts](https://echarts.apache.org/en/index.html)。

## 2. 页面与操作

| 页面/路由 | 主要内容 | 可以直接操作 | 依赖 API |
| --- | --- | --- | --- |
| 数据中心 `/data` | 数据集覆盖、质量、可用时间、最近更新 | 筛选、查看缺口、创建更新、发布快照 | datasets、batches、ingestions、snapshots |
| 数据源 `/connections` | 适配器、连接版本、权限和能力状态 | 添加连接、填写参数/密钥、测试连接、上传文件 | providers、secrets、connections、imports |
| 标的池 `/universes` | 静态名单/历史规则、样本数量、版本 | 创建规则、筛选条件、查看历史成员 | universes、universes/:id/resolve |
| 因子库 `/factors` | 因子家族、版本、依赖、可计算状态 | 参数配置、组合表达式、预览、计算 | factors、factor-runs/preflight、factor-runs |
| 因子详情 `/factors/:id` | 分布、覆盖率、IC、分组收益、相关性 | 时间选择、查看缺失原因、导出结果 | factor-runs/:id/analysis、artifacts |
| 策略工作台 `/strategies` | 模板、假设、因子版本、筛选排序、权重和调仓 | 新建、复制版本、表单配置、查看依赖 | strategy-templates、strategies、models |
| 新建回测 `/backtests/new` | 数据快照、标的池、策略、资金、成本、样本划分 | 运行预检、定位问题、启动回测 | backtests/preflight、backtests |
| 回测详情 `/backtests/:id` | 进度、净值/回撤、基准、持仓、订单、费用 | 取消、查看逐笔原因、导出 | jobs、report、records、exports |
| 实验中心 `/experiments` | 参数与版本、指标、时间划分和历史试验 | 搜索、选择对比、重跑、下载研究包 | experiments、compare、backtests、exports |
| 任务中心 `/jobs` | 更新、因子、回测、导出任务统一列表 | 进度、日志/错误、取消、失败重试 | jobs、events |

界面采用固定的“研究上下文条”：显示当前快照、标的池、策略版本及时间范围，防止比较实验时混淆数据与参数。技术哈希放详情中，常规操作显示可理解的名称与版本。

## 3. 完整操作流程

1. 添加数据连接或上传已有文件；表单由已注册 schema 渲染，给出字段解释和能力限制。
2. 选择数据集、标的范围、时间区间和更新模式；“强制重新获取”明确说明会重新请求上游。
3. 查看质量结果，错误定位到字段/时间范围；数据不足时给出补数操作，不显示虚假的健康状态。
4. 发布快照，再选择历史标的池。快照可追溯且不可原地修改。
5. 选择因子并修改参数；页面显示“可计算 / 缺数据 / 历史不足 / 时点证据不足 / 不适用”。缺失依赖链接回数据中心。
6. 选择策略模板，配置筛选、排序、权重、调仓、退出和风险限制；保存产生新版本。
7. 填写回测配置并预检；全部阻塞项清除后启动。若允许探索模式，相关限制必须随结果持续显示。
8. 运行后跳转详情，任务在离开页面或断线后继续；刷新可恢复状态。
9. 完成后查看报告、逐笔因果链和成本；重跑产生新实验。对比先检查币种、区间、基准与指标口径，差异明确提示。
10. 导出报告、数据或研究包；任务完成后在界面下载。

## 4. 可视化配置边界

首期无需写代码即可组合已注册因子和模板：选字段/因子 → 运算 → 过滤 → 排序 → 选取 → 权重 → 调仓。表达式通过白名单 AST 存储，不用前端拼任意 Go 代码。

操作节点显示所需输入、输出单位、参数和错误。表达式可以表单或受限公式编辑，暂不强制复杂拖拽画布；若以后增加拖拽，必须同时有键盘/表单操作方式。

自定义新算法由开发者实现 Go Factor/StrategyFactory，注册参数 schema 后自动出现在界面。高级策略所需参数可扩展，但所有执行语义仍由后端校验。

## 5. 统一交互契约

- 列表统一服务端分页；搜索、筛选、排序和分页状态写入 URL。切换过滤条件回到首屏。
- 中文输入法组合输入期间不触发搜索；远程搜索防抖 300ms，清除立即生效，旧请求不能覆盖新结果。
- 新建配置/版本成功返回对应列表并高亮新项；启动长任务进入任务/运行详情。取消编辑回到来源位置。
- 表单保留输入、按字段显示错误、提交时聚焦首个错误。提交禁用重复点击，但后端幂等仍必需。
- 离开未保存配置时提示；日常可逆保存不弹重复确认。取消运行说明后果并调用应用内确认框。
- 统一加载、空数据、无搜索结果、失败、部分结果、无权限、断线和陈旧数据状态；关键错误留在页面，不能只用一条消失的 toast。
- 任务进度优先显示阶段与处理条数；总量未知时显示不确定进度，不伪造百分比。请求取消后显示“正在取消”，仅终态显示“已取消”。
- SSE 断线先重放，失去事件窗口后重新读取状态；网络中断不自动新建任务。重试保留原任务链接。
- 密钥默认遮罩，只允许一次写入；页面不回读明文。权限失败提供重新登录或联系管理员的可执行路径。
- 所有下载、逐笔明细和图表都有后端数据依据；图表降采样仅影响展示，不改变统计与导出。

## 6. 图表与报告

净值和回撤共用时间轴，清楚标示基准、训练/验证/测试区间及缺失段。收益、费用、滑点、暴露分别可查看；不能只展示最优指标。

因子页面提供分布、覆盖、时间序列和选股适用的 IC/分组收益。策略对比固定同一指标定义；不兼容数据用说明或分栏，不无条件拼在同一排行榜。

每个统计值可查看单位、年化频率、无风险利率、基准和缺失处理。值为 null 时显示原因，不能显示成 0%。

## 7. 设计、可访问性与验收

视觉方向见 [DESIGN.md](../DESIGN.md)。默认简体中文，界面时间显示明确时区；交易日历与市场时区由模型决定，不根据界面语言推断。数字使用等宽数字，收益方向同时标示正负号，不只依赖红绿颜色。

桌面研究为主：左侧导航、中部表格/图表、右侧参数或详情。窄屏改为顺序面板，图表和表格允许局部横向滚动；不隐藏必要操作。遵循 WCAG 2.2 AA，包含键盘操作、可见焦点、语义标签、图表文字摘要和减少动态效果。

实施验收必须在真实浏览器覆盖成功、失败、加载、空结果、断线恢复、键盘及窄视口；同一操作在数据、因子、实验页面行为一致。本轮只有文档，没有声称通过这些运行验收。
