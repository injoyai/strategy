# 因子库与数据源需求

版本：0.1，2026-09-12。这里将“需要什么数据”和“向谁取得数据”分开。股票类因子重点展开，其他资产另列扩展；尚未选定首期市场或供应商。

## 1. 数据分层

| 层级 | 数据 | 用途 |
| --- | --- | --- |
| 原始层 | 上游原始响应、请求范围、抓取时间、供应商版本、校验和 | 审计、重清洗、问题定位 |
| 标准层 | 统一代码、字段、单位、时间、缺失原因、修订版本 | 跨供应商查询与可复现快照 |
| 衍生层 | 收益序列、TTM、估值重算、因子矩阵及标签 | 固定计算口径，复用计算 |

PE 属于估值指标，既可以采购历史 PE，也可以从历史股本、价格和当时已披露利润计算。只有今天的 PE 不能用于多年历史回测；只有 K 线不能完整支持财务、质量和估值因子。

## 2. 需要准备的数据集和字段

优先级：A 为基础，B 为估值/财务家族必需，C 按研究方向扩展。优先级不是供应商可用性承诺。

| 数据集键 | 数据内容与最小字段 | 时间/更新要求 | 优先级 |
| --- | --- | --- | --- |
| instrument | instrument_id、市场、场所、代码历史、资产类、币种、上市/退市日期、发行主体映射 | 历史有效区间，不只保存当前列表 | A |
| calendar | 交易日、时区、交易时段、半日市/特殊时段 | 按场所和有效版本保存 | A |
| bar | 开高低收、成交量、成交额、周期开始/结束、是否完成；有则保留成交笔数 | 先选一个频率；周/月可按交易日历聚合；缺口有标记 | A |
| corporate_action | 拆并股、送转、分红、配股等类型、公告/生效/除权/支付日期、现金及股数变化 | 保存原始事件和修订 | A，股票类 |
| adjustment | 复权因子、基准日、方法、版本、可用时间 | 研究价格可派生；成交与账本不直接用复权价 | A，股票类 |
| trading_status | 历史停复牌、风险警示、可交易状态、价格限制、交易单位 | 按交易日或生效区间；不能用当前状态覆盖历史 | A |
| benchmark | 基准行情、价格/全收益口径、币种、必要时无风险利率序列 | 与策略收益时区、日历、币种对齐 | A |
| membership | 指数/行业分类体系、版本、成分、权重、生效与失效时间 | 历史成分，用于标的池、行业中性化和归因 | A/B，视研究配置 |
| share_capital | 总股本、流通股本、自由流通股本、生效时间、公告时间 | 保存变动历史；三类股本不得混用 | B |
| valuation | PE、PE_TTM、PB、PS、PS_TTM、总市值、流通市值、股息率、换手率 | 每日历史值、原始口径、可用时间；缺失不是零 | B |
| income | 营业收入、营业利润、利润总额、净利润、归母净利润、EPS | 报告期、累计/单季、合并/母公司、公告、修订、币种 | B |
| balance_sheet | 总资产、总负债、归母权益、现金、有息负债、存货、应收账款 | 时点余额；不能按流量方式直接求 TTM | B |
| cash_flow | 经营现金流净额、投资/筹资现金流、资本开支相关原始科目 | 区分累计/单季，保存公式映射和公告时间 | B |
| financial_indicator | ROE、ROA、利润率、杠杆率、增长率等供应商衍生指标 | 保存分母、平均/期末口径和公式版本；允许独立重算校验 | B |
| dividend | 分红方案、每股现金、报告期、公告、实施状态、除息与支付日期 | 预测方案与已实施分红分开 | B |
| money_flow | 分档买卖金额/量、净流入及供应商分档口径 | 历史覆盖和方法版本；净流入不是统一市场事实 | C |
| margin | 融资余额、买入/偿还、融券余量/卖出、标的资格 | 实际发布时间及历史资格 | C |
| ownership | 股东人数、机构/基金持仓、前十大股东、解禁信息 | 报告期与披露日分开；披露滞后不可回填 | C |
| forecast | 分析师预测、目标价、预测期、机构、修订与发布时间 | 保存历史预测版本，不能只用最新一致预期 | C |
| event | 公告、业绩预告/快报、回购、增减持、处罚等结构化事件 | 真实发布时间、事件类型、原始来源、修订 | C |
| macro | 利率、收益率曲线、经济统计值、发布时间、历史发布版本 | 区分初值和修订值 | C |
| quote_trade | 逐笔成交、买卖报价/档位、数量、场所序列号 | 用于盘口、价差及微观结构；需确认历史权限和时钟质量 | C |

例如 Tushare 的历史日线包含 OHLC、成交量和成交额，复权因子独立提供；接入时必须按该接口标注的原始单位进行映射。[日线文档](https://tushare.pro/document/2?doc_id=27)、[复权因子文档](https://tushare.pro/document/2?doc_id=28)

Tushare 的 daily_basic 提供 PE/PE_TTM、PB、PS、股本、市值、股息率等；其文档注明部分比例用百分数、股本用万股、市值用万元，并对亏损 PE 使用空值。这些是供应商口径，标准层需要转换并保留原始定义。[每日指标文档](https://tushare.pro/document/2?doc_id=32)

## 3. 因子家族与数据依赖

以下是拟支持的因子定义，不代表收益有效性。窗口数字是可配置公式参数的例子，不是已确定交易参数。

| 家族 | 因子例子/定义 | 必需数据 | 关键处理 |
| --- | --- | --- | --- |
| 收益与动量 | N 期收益 P(t)/P(t-N)-1；跳过最近 K 期的动量 | bar、adjustment/corporate_action、calendar | 明确价格收益或含分红总收益口径；窗口按有效交易期 |
| 反转 | 最近 N 期收益的相反数 | 同上 | 与长期动量分开评估，加入换手成本 |
| 趋势 | 均线偏离、均线交叉、MACD、突破幅度 | OHLC | 预热窗口和同 Bar 交易时序固定 |
| 波动 | 收益标准差、下行波动、ATR | 收益或 OHLC | 年化频率显式；ATR 为价格量纲，可另定义 ATR/价格 |
| 量价 | 成交量变化、量价相关、OBV、成交额均值 | OHLCV、amount | 停牌与真实零量分开；拆股后价格/量口径匹配 |
| 流动性 | 换手、成交额、Amihud 非流动性均值(abs(return)/amount) | bar、股本 | 零成交额返回缺失，不能除零；日频通常只是代理指标 |
| 规模 | log(总市值)、log(流通市值) | 原始价格、share_capital 或 valuation | 市值必须为正；与复权价格乘股本区分 |
| 价值 | E/P、B/P、S/P、现金流收益率 | valuation 或财务报表+股本+价格 | 负利润/负权益政策显式；现金流收益率定义独立 |
| 分红 | 过去窗口现金分红收益率、分红稳定性 | dividend、价格 | 宣告/实施和窗口口径固定，不能使用未来已知分红 |
| 盈利质量 | ROE、ROA、毛利率、经营利润率 | income、balance_sheet | 明确归母/合并、平均权益/期末权益和异常分母 |
| 现金质量 | 经营现金流/净利润、应计项 | cash_flow、income、balance_sheet | 净利润接近零时按定义处理；应计项公式有版本 |
| 成长 | 收入/利润同比、资产增长 | 历史财报 | 比较相同口径；基期非正时标记不可比，不强套同比公式 |
| 偿债/杠杆 | 负债/资产、净债务、利息保障倍数 | balance_sheet、income | 金融企业适用性单独声明 |
| 运营效率 | 存货/应收周转、资产周转 | 财报 | 流量与平均余额对应，避免期末余额代替而不注明 |
| 风险暴露 | Beta、残差波动、行业/规模暴露 | 标的与基准收益、历史行业、市值 | 回归样本对齐、最少样本数、滞后和缺失规则固定 |
| 资金行为 | 分档净流入、融资变化 | money_flow、margin | 不同供应商定义不能无条件拼接 |
| 预期与事件 | 盈利预测修正、业绩惊喜、回购事件 | forecast、event、价格 | 预测版本和公告真实可用时间是必要条件 |
| 盘口微结构 | 买卖价差、订单簿不平衡、主动成交比例 | quote_trade | 不能仅用日线伪造这类因子 |

供应商财务指标包含公告日期等元数据，但存在公告日期不等于已经具备完整历史修订或精确日内可用性，需单独验收。[财务指标文档](https://tushare.pro/document/2?doc_id=79)

## 4. PE/PB 等估值口径

平台至少区分 `pe_annual`、`pe_ttm`、`pe_forward`，不将供应商含混的 `pe` 自动解释为同一指标。

- `market_cap_total = raw_close × total_shares`，币种、价格日期、股本有效日期必须匹配。
- `pe_ttm = market_cap_total / net_profit_parent_ttm` 是本平台拟定义的一种口径；与供应商不一致时保留各自字段和口径，不能混写。
- `ep_ttm = net_profit_parent_ttm / market_cap_total`。可以按因子定义保留负盈利收益率；不能依赖把供应商空 PE 取倒数恢复负利润。
- `bp = common_equity_parent / market_cap_total`。权益扣除项目需要数据与公式版本；供应商 PB 不必与该口径天然相同。
- `sales_yield = revenue_ttm / market_cap_total`；市现率、自由现金流收益率需各自命名和依赖，不能都叫现金流因子。
- TTM 流量由连续四个可用单季值组成；累计财报先按同一会计口径差分得到单季值，缺季度不自动凑齐。同比和修订都按当时可用版本计算。
- 总资产、权益等余额使用时点或平均值，不进行四季度简单累加。
- PE 与成长率合成 PEG 时，明确增长率单位、预测/历史口径和非正值处理；列为后续扩展。

这些是平台设计定义；实际供应商字段映射须用具体接口文档及样本核验。

## 5. 时间与修订：数据接口强制字段

| 字段 | 含义 |
| --- | --- |
| instrument_id / entity_id | 证券与发行主体分开；财务归属主体通过历史映射关联证券 |
| event_time | 观测所对应的事件时间，例如 Bar 结束时刻 |
| period_end | 财务报告期末等经济归属期，不能替代可用时间 |
| published_at | 公开发布时间，未知则 null，并标记原始精度 |
| available_at | 依据证据和已版本化政策确定的最早研究可用时间 |
| ingested_at | 本系统首次收到该版本的时间 |
| revision_id / supersedes_revision_id | 修订标识及被替代版本，不能覆盖旧值 |
| effective_from / effective_to | 股本、成分、交易状态等的有效区间，左闭右开 |
| source_id / source_record_id | 来源连接及上游记录标识 |
| schema_version / policy_version | 字段、单位和可用时间政策版本 |
| quality_flags / missing_reason | 缺失、过期、仅日期时间、非正分母、上游不支持等标记 |

历史查询先限制快照中存在的版本、`available_at <= decision_time`，再按自然键取当时有效的最新修订；对状态类记录还检查有效区间。真实运行回放额外约束 `ingested_at <= replay_time`。后来的采集时间与历史公开时间不能混为一谈。

对没有历史版本证据的重述财报或供应商回填数据，标记 `pit_unverified`。严格研究模式拒绝依赖这类数据；探索模式可运行但报告必须持续显示限制，不得显示为已通过严格验证。

## 6. 数据供应商接入评估

不在本轮锁定采购。接入前逐项核查覆盖、历史长度、授权、限流、复权、修订、时点证据、缺失率、Go/HTTP 接入方式及导出限制。接口存在不等于当前账号有权限，也不等于能稳定取得所需历史。

| 接入方向 | 当前定位 | 接入前必须验证 |
| --- | --- | --- |
| Tushare Pro | 股票行情、估值和财务数据候选；官方目录列有相关接口 | 所需市场、频率、历史与修订覆盖，实际账号权限、批量效率和字段口径 |
| 交易所/指数公司公开或授权数据 | 交易规则、日历、证券与指数资料的候选权威来源 | 机器获取方式、历史完整性、授权和更新保障，不默认免费批量可得 |
| 商业数据服务商 | 当精确历史修订、分钟/逐笔或团队授权需要时评估 | 样本验收、预算与许可；具体厂商待选择 |
| 已有行情服务/本地文件 | 复用用户已有数据资产的通用入口 | 格式、历史深度、单位、复权、时间证据与来源许可；不能据当前文件推定多年覆盖 |
| CSV/Parquet 导入适配器 | 本地已有数据、合成数据、验收样本 | 模板映射、类型、单位、时区、错误行报告、校验和和历史元数据 |

Tushare 官方目录列有行情、估值、财务及其他数据类型，可作为候选清单的核查入口；本项目不复制目录中的积分或价格作为固定采购条件。[官方接口与权限目录](https://tushare.pro/document/1?doc_id=108)

## 7. 建议的数据建设顺序

1. **价格研究包**：证券主数据、交易日历、原始 K 线、交易状态；股票补公司行为/复权、基准和所需历史成分。支持动量、反转、趋势、波动与量价。
2. **估值研究包**：在价格包上增加历史股本、PE/PB/PS、市值、股息。支持规模、价值、换手和分红类研究。
3. **财务研究包**：三大报表、公告与修订、会计口径、行业分类。支持独立重算估值、质量、成长、杠杆及行业中性化。
4. **增强研究包**：资金、融资、持仓、预期、事件、宏观或盘口，按策略需求采购与接入。

数据中心显示每个因子的状态：`可计算`、`缺字段`、`历史不足`、`时点证据不足`、`不适用该资产`。不能将未知值填成 0 来启用因子。

## 8. 非股票资产的扩展

| 方向 | 在基础行情外增加 | 对因子库的影响 |
| --- | --- | --- |
| ETF | 份额、净值、分红、跟踪指数、必要时申赎篮子 | 折溢价、跟踪误差、份额流量；不能无说明直接套上市公司 PE |
| 期货 | 合约乘数、到期、结算、持仓量、保证金、主力映射、现货/仓单 | 期限结构、基差、展期、持仓变化；连续合约不能直接当真实成交合约 |
| 加密现货/衍生品 | 场所元数据、交易精度、资金费率、持仓量、指数/标记价格 | 资金费率、基差、跨场所与持仓因子；PE 多数不适用 |
| 期权 | 合约条款、标的、波动率曲面、利率/分红、行权与到期规则 | Greeks、波动率与偏度；需要独立估值和风控模型 |
